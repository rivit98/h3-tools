# H3 Lobby API

The goal of this project was to provide an API for retrieving and analyzing Heroes 3 game history data.

After returning to the project following approximately one year of inactivity, I discovered that https://hotameta.com/ had been created and already provides the functionality (and many others!) I originally intended to implement.

The codebase is incomplete and several components are still missing, including:

* login/registration flow
* fixing imports after code reorganization
* webserver implementation
